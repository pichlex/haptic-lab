# Changelog

All notable changes to Haptic Lab are documented here. The project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and intends to use [Semantic Versioning](https://semver.org/) after the public API stabilizes.

## [Unreleased]

### Added

- Haptic Lab brand system: SVG mark, lockup, banner, favicon, Apple touch icon, and repository social preview.
- Product-focused English landing page links to the project and the author profile.
- Full package documentation, browser support matrix, API reference, roadmap, limitations, and project structure.
- Structured GitHub issue forms and repository contribution guidance.

### Changed

- Refined the landing page to a restrained graphite-and-signal-orange product system.

## [0.1.0-alpha.1] - 2026-08-03

### Added

- `HapticRange`, `HapticDial`, and `HapticXYPad` interaction primitives.
- Haptic tap and toggle bindings.
- TypeScript declarations, unit tests, CI, and GitHub Pages workflows.
- Static component gallery in `site/`.
