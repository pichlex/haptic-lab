# Roadmap

## Release blockers

- Device-version test matrix for physical iPhones and WebKit builds.
- Stable public API and semantic-versioning policy.
- Browser automation for desktop input and accessibility.
- Type declaration review against the final JavaScript API.
- npm trusted publishing or provenance-enabled release workflow.

## Later

- React, Vue, and Web Component adapters.
- Optional Android Vibration API adapter.
- Lower-level detent scheduler primitives.
- Visual themes maintained outside the core package.
