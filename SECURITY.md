# Security Policy

## Supported versions

Haptic Lab is currently an experimental alpha. Security fixes are applied to the latest commit on `main`.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue.

Use GitHub's private vulnerability reporting for this repository when available, or contact the maintainer through the email address associated with the GitHub profile at [pichlex](https://github.com/pichlex).

Include:

- affected version or commit
- browser and operating system
- a minimal reproduction
- expected and actual behaviour
- potential impact

## Scope

Relevant reports include:

- DOM injection or unsafe HTML handling
- unexpected navigation or origin access
- package supply-chain issues
- insecure deployment examples
- accessibility behaviour that creates a security or privacy risk

Browser limitations or missing haptic support are compatibility issues rather than security vulnerabilities unless they create a concrete security impact.
